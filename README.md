
A website that imports complexity results for MDPs (and whatever else specified) into a graph to visualize gaps and previous results in a more accessible form.  Takes results, valid result entries and graph structure from jsons to be easily extendable.

It is currently accessible in a very rough state at the linked github page.

Developer installation requirements (rough):
Install ![bun](https://bun.com/get), and run 'bun install' after restarting.
