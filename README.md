
A program that imports complexity results for MDPs (and whatever else specified) into a graph to visualize gaps and previous results in a more accessible form.  Takes results, valid result entries and graph structure from jsons to be easily extendable.

A list of papers whose complexities have been included can be found in the "Papers.txt" file.

This project can be launched using "bun run tauri dev" in the console. Bun will likely need to be installed, though alternatives, i.e node.js might also work just fine.  This will launch it in a desktop window and host it on localhost for now.
